# Working session summary — 18 September 2026

## Goal

Investigate whether a jailbroken iPhone 7's cellular call hardware can be turned into a call bridge
that is usable from a stock Xiaomi 15 over the local network.

## Progress

1. Initial access was done through Screen Sharing/TrollVNC and NewTerm 3. The on-screen keyboard,
   animations and paste limitations slowed the work down.
2. NewTerm 2 turned out to be designed for non-rootless jailbreaks; work continued with NewTerm 3
   on the rootless device.
3. Procursus OpenSSH Server was installed. The initial `connection refused` was resolved by
   enabling the service, and SSH access to the device's LAN address was established.
4. A full device report was collected. The device was confirmed as an `iPhone9,3` running
   iOS 15.8.8 with a rootless `/var/jb` environment.
5. The TrollRecorder app bundle was copied to the Mac for static review. Private entitlements
   related to telephony tap, system-wide audio tap, background recording and call modification were
   observed.
6. The open TrollRecorder and TrollVNC repositories were compared. TrollVNC offers nearly complete
   sources and a ready GitHub Actions pipeline; the TrollRecorder repository only offers the
   GPL-licensed CLI core. The Pro app and its licensing/persistence code are not in the open
   repository.
7. A rootless GitHub Actions workflow was prepared for the TrollRecorder CLI. The first run failed
   with `$THEOS does not exist`; the SDK installation step was fixed by exporting
   `THEOS=$GITHUB_WORKSPACE/theos`.
8. The `audio-commands` 0.1 package was built successfully and installed with Sileo. The
   `call-monitor`, `call-recorder`, `audio-player`, `audio-recorder`, `audio-mixer` and
   `dtmf-decoder` tools landed under `/var/jb/usr/local/bin`.
9. In the first test an empty `BASE` variable caused redirections to target the `/` root and
   produced a read-only filesystem error. The scripts moved to absolute
   `/var/mobile/CallBridgeResearch/...` paths.
10. In the second test `call-monitor` and `call-recorder speaker` both worked. During a real GSM
    call the caller's number, the call state and 29.234 seconds of downlink audio were captured.
11. The CAF file was copied to the Mac; QuickTime opened it directly and the far end was clearly
    audible.
12. Build packages, static review files, private and masked evidence, and the project documentation
    were consolidated into a single organized project folder.

## Most important outcome

Call detection and access to the far-end audio are no longer assumptions; they are measured,
reproducible evidence on real hardware. The next technical gate that decides the project's
viability is injecting network-sourced audio into the cellular uplink.

## Decisions taken

- Instead of trying to bypass paid TrollRecorder features, the open CLI core and our own service
  will be used.
- Raw phone numbers and conversation audio stay in the private evidence folder.
- Call control and uplink injection will be proven first; the Android UI will be grown afterwards.
- Persistence will be provided by our own rootless LaunchDaemon.
